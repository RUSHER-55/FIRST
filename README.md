## 🌐 Deploy to GitHub Pages (1-Click)
1. Initialize Git and commit:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of Aniket Panara zero-gravity portfolio"
   ```
2. Push to your GitHub repository:
   ```bash
   git remote add origin https://github.com/aniketpanara/portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. In GitHub repo settings, go to **Pages** > **Deploy from a branch** > select `main` and `/ (root)`. Your portfolio will be live in 60 seconds!
